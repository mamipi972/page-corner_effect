Page Effects

Un plugin JavaScript sans dépendance pour soulever / tourner un coin de page et créer des effets de papier déchiré.

1. Coin de page qui tourne

Survolez le coin inférieur droit, puis tirez-le. Relâchez au-delà d'un tiers de la diagonale pour tourner la page et révéler le dessous.

Glissez le coin →

2. Coins cornés statiques

Les quatre coins, avec un soulèvement au repos (option peel). Chacun reste interactif.

bas droit
bas gauche
haut droit
haut gauche

3. Bords déchirés

Mode edge : dentelure fibreuse, frange blanche du papier et ombre portée.

Note

Page arrachée d'un carnet : seul le bas est déchiré.
BILLET · N° 0042

Tous les côtés

Un morceau de papier déchiré de partout.

4. Trou déchiré

Mode hole : un trou arraché dans la page laisse voir le contenu placé dessous.

AFFICHE

5. Bande arrachée avec rouleau

Mode strip : une bande se déchire et s'enroule. Tirez le rouleau ou utilisez les boutons.

Tirez le rouleau →

Utilisation

<script src="src/page-effects.js"></script>
<script>
  // Coin qui tourne
  const curl = PageEffects.pageCurl('#photo', {
    corner: 'br', hoverPeel: 70, under: 'images/dessous.jpg'
  });
  curl.turn();            // tourner la page
  curl.reset();           // revenir

  // Papier déchiré
  PageEffects.paperTear('.note', { mode: 'edge', sides: ['top', 'bottom'] });
  PageEffects.paperTear('#affiche', { mode: 'hole', under: '#1a1a1a' });
  const tear = PageEffects.paperTear('#bandeau', { mode: 'strip', strip: { progress: 0 } });
  tear.tearTo(1);         // anime l'arrachage
</script>

<!-- ou sans JavaScript, par attributs -->
<div data-page-curl='{"corner":"tl","peel":60}'>…</div>
<div data-paper-tear='{"mode":"edge","sides":"all"}'>…</div>
